# Эврика — ИИ-консультант по продажам EdPalm

Репозиторий `evrika-sales-bot`: исходная техническая основа Roberta для будущего
ИИ-продавца по ТЗ EdPalm.

## Текущий статус

Выполнено переименование пакета `roberta` → `evrika` и соответствующих импортов.
Продажная логика пока не реализована. Унаследованные системные промпты всё ещё
описывают разговорного персонажа; прежде чем использовать с клиентами, их нужно
заменить вместе с бизнес-логикой. Пример persona не отменяет эти старые промпты.

Текущий код использует AWS Bedrock и пользовательский аккаунт Telegram через
Telethon. Подключение Polza.ai и обычного Telegram Bot API — следующие этапы.
Это отдельная основа; ранее написанный терминальный прототип сюда не объединён.

Код и тесты в ходе подготовки репозитория не запускались. Старые проверки
персоны потребуют обновления под новые требования.

## Что перенесено

- исходники Python и зависимости;
- SQLite-хранилище истории и краткой памяти;
- очередь сообщений, пауза и дедупликация;
- учёт токенов и количества запросов;
- исходные тесты с обновлёнными импортами.

## Что не публикуется

Ключи `.env`, оригинальная личная persona, переписки, базы SQLite, сессии аккаунта,
данные Telegram Desktop, исполняемые файлы и виртуальное окружение.
Вместо личных настроек включены `.env.example` и `persona.example.json`.
Оригиналы остаются в исходной папке и не изменяются.

## План адаптации под ТЗ

1. Отделить ядро диалога от Telegram, добавить терминальный интерфейс.
2. Добавить провайдер Polza.ai и общий контракт вызова LLM.
3. Реализовать состояние клиента, квалификацию и разрешённые действия.
4. Добавить каталог, базу знаний, правила рекомендаций и проверки ответов.
5. Разделить сжатый контекст модели и сохраняемую историю для менеджера.
6. Проверить диалоги в терминале, затем подключить Telegram-бота.
7. Позже подключить Bitrix24, Salebot, портал и подтверждения оплаты.

Автоматический запуск или подключение сервисов при публикации не выполняется.
