# Эврика · ИИ-продавец EdPalm

Telegram-бот, который консультирует родителей онлайн-школы EdPalm, подбирает программу из каталога, ведёт клиента по воронке продаж из ТЗ и передаёт менеджеру готовую карточку лида.

[Каталог продуктов](docs/catalog.txt) · [Скрипты продаж и примеры диалогов](docs/sales_scripts.txt)

## Что умеет

- Отвечает на свободные вопросы в личных сообщениях Telegram, короткими сообщениями с имитацией набора текста.
- Ведёт воронку: квалификация, выявление потребности, 1 тариф + 1 альтернатива, презентация ценности, отработка возражений, обязательный призыв к действию.
- Цены и ссылки берёт только из каталога (51 карточка с сайта школы); спорные карточки описаны отдельными правилами.
- На каждом ходе модель возвращает JSON: сообщения клиенту и карточку лида (`crm_state`): этап воронки, категория HOT / WARM / INFORMATIONAL / NON-TARGET, SLA, данные клиента, рекомендованный тариф, возражения, резюме для менеджера.
- Передача менеджеру: после согласия клиента карточка лида уходит в чат `ADMIN_CHAT_ID`, а лид пишется в `data/bitrix24_leads_outbox.jsonl` в формате для `crm.lead.add`.
- Если клиент молчит на коммерческом этапе 15 минут, бот один раз напоминает о себе и уведомляет менеджера.
- Память: у каждого собеседника своя база SQLite; длинный диалог сжимается в резюме без персональных данных. Общие лимиты вызовов модели.

## Как устроено

| Файл | Назначение |
|---|---|
| `evrika/telegram_app.py` | Telegram-клиент (Telethon), очередь сообщений, передача лида, напоминания |
| `evrika/prompts.py` | Сборка промпта: персона, каталог, память, формат ответа |
| `evrika/humanizer.py` | Разбор JSON-ответа модели на сообщения и карточку лида |
| `evrika/bedrock.py` | Вызов модели через AWS Bedrock Converse API |
| `evrika/store.py` | SQLite: история, память, лиды, счётчики вызовов |
| `evrika/memory.py`, `evrika/privacy.py` | Сжатие длинного диалога и фильтр персональных данных |
| `persona.json` | Правила продавца: воронка, квалификация, возражения, запреты, триггеры передачи |
| `knowledge_base.json` | Каталог школы: 51 карточка с ценами и ссылками, правила спорных цен |
| `tests/` | Офлайн-тесты без сети и без вызовов модели |

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # заполнить ключи Telegram и AWS

python -m unittest discover -s tests -v    # тесты, без сети
python -m evrika --check-aws               # проверить настройки AWS локально
python -m evrika --test-bedrock            # один тестовый запрос к модели
python -m evrika --simulate "Сколько стоит обучение в 7 классе?"   # ответ без Telegram
python -m evrika                           # запустить Telegram-бота
python -m evrika --usage                   # расход вызовов и токенов
```

При первом запуске Telethon попросит номер телефона и код из Telegram. Команды в чате с ботом: `/stop`, `/start`, `/forget`.

## Ограничения MVP

- Бот работает от пользовательского аккаунта Telegram (Telethon). Для продакшена нужен официальный Bot API.
- В Bitrix24 лиды пока не отправляются через API: они копятся в `data/bitrix24_leads_outbox.jsonl`.
- Каталог — снимок сайта; спорные цены требуют подтверждения школы.
- Для тестов используйте вымышленные данные. Переписки хранятся локально в `data/` и в Git не попадают.
